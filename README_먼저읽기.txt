생각키움 SNS 매니저 Mobile PWA
================================

무엇인가요?
- 갤럭시/아이폰에서 브라우저로 실행되는 모바일 웹앱입니다.
- 주소를 홈 화면에 추가하면 일반 앱처럼 사용할 수 있습니다.
- 수업사진 선택 → 전면 얼굴 판별 → 필요한 사진 비식별 편집
- 네이버 블로그 글 + 인스타그램 글 + 해시태그 생성
- 생각키움연구소 지역 키워드를 지점/내용에 맞게 자동 선별

중요한 구조
- OpenAI API Key는 스마트폰에 저장하지 않습니다.
- 서버의 환경변수 OPENAI_API_KEY에 저장합니다.
- 그래서 이 폴더를 인터넷 서버(Render/Railway/Fly.io/VPS 등)에 한 번 배포해야 휴대폰 어디서든 사용할 수 있습니다.

가장 쉬운 배포 예시: Render
1. 이 폴더를 GitHub 저장소에 업로드
2. Render에서 New > Web Service
3. GitHub 저장소 선택
4. Docker 환경으로 배포
5. Environment에 OPENAI_API_KEY 등록
6. 배포된 https://... 주소를 스마트폰에서 열기
7. 삼성 인터넷/Chrome 메뉴 → '홈 화면에 추가'

로컬 테스트
1. Python 3.11 이상
2. pip install -r requirements.txt
3. Windows PowerShell:
   $env:OPENAI_API_KEY="발급받은키"
   uvicorn app:app --host 0.0.0.0 --port 8000
4. PC에서 http://127.0.0.1:8000

사진 보호 방식
- 정면/준정면 얼굴 또는 개인정보가 보이는지 AI가 먼저 판별
- 필요한 사진만 비식별화
- 원본 얼굴과 동일인이 아님이 분명하도록 재구성
- 단순 모자이크 대신 자연스러운 수업사진 형태
- 이름/학교명/전화번호 등 텍스트 개인정보 제거 지시
- 실제 게시 전 사람이 최종 확인해야 합니다.
