📌 사용 방법
  1. 이미지 수·비율을 선택하고, 원하면 교실 참고사진을 첨부합니다.
  2. 참고사진이 있다면 활용 방식(A/B)을 선택하세요.
  3. Gemini 연속 제작 모드를 선택하세요 (기본: 독립 장면).
  4. [장면 기획 시작]을 누르면 AI가 블로그 내용에 맞는 장면을 분석합니다.
  5. 카드마다 [프롬프트 복사] → [Gemini 열기]로 이미지를 생성하세요.
  6. 생성한 이미지를 [이미지 업로드]로 등록하면 해당 카드에 연결·저장됩니다.

⚠️ 참고사진 B모드·연속 모드 3은 Gemini 채팅창에 직접 첨부해야 합니다. SNS 매니저에서 자동 전달되지 않습니다.

⚠️ AI 생성 이미지는 실제 수업·학부모 후기 증거로 소개하지 마세요.
