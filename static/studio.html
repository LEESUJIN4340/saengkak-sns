PC와 휴대폰에서 같은 비공개 사진을 사용합니다. 사진은 공개 이미지 폴더에 저장하지 않습니다.

관리자 로그인

1. 지점별 사진 등록

얼굴 사진은 본인 사진만 등록해 주세요. 이미지 제작 시 선택한 사진이 OpenAI 이미지 API로 전송됩니다.

2. 본문에 맞는 실사 이미지 제작

학생 활동 연출은 실제 수업 사진이 아닌 AI 연출 이미지입니다. 원본 교실의 구조는 최대한 유지합니다.사진을 여러 장 선택하려면 PC에서는 Ctrl 키를 누르고 클릭하세요. 휴대폰에서는 사진을 각각 등록한 뒤 이 목록에서 선택하세요. 실제 기물 형태를 참고하지만 AI 생성 결과의 정확성을 보장하지는 않습니다.
예상 기본 이미지 출력 요금: 1장 $0.133 (고화질 1024×1024, GPT Image 1.5 기준). 원화 약 193원 (환율 1달러=1,450원 가정). 참고사진 입력 토큰 비용이 별도로 추가되므로 실제 청구액은 더 높을 수 있습니다. Render의 OPENAI_IMAGE_MODEL 설정이 다른 경우 이 표시는 적용되지 않습니다. 실제 가격은 OpenAI 공식 요금표를 확인하세요. 결과물은 게시 전에 검수하세요.
